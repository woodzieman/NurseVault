Notes
  • Criteria for selecting the Ill Appearing LR
    • Need for HCPAP, HFNC, or mechanical ventilation
    • Need for vasoactive drugs
    • Encephalopathy, perinatal depression, seizures, or 5-minute Apgar <5
    • Need for O2 support for 2 or more hours to keep oxygen stauration ≥90%
  • Criteria for selecting the Equivocal exam LR
    • Heart rate ≥160
    • Respiratory rate ≥60
    • Temperature ≥100.4 degF or <97.5 degF
    • Respiratory distress
  • EOS: Early-onset sepsis; ROM: rupture of membranes; GBS: group B strep; LR: likelihood ratio; NICU: neonatal intensive care unit.

 
Equations used
 
EOSrisklogit = LocalincidenceEOS + (0.868 * Highestantepartummaternaltemperature) - (6.9325 * (Gestationweeks + (Gestationdays / 7))) + (0.0877 * sq(Gestationweeks + (Gestationdays / 7))) + (1.2256 * HourssinceROM+0.050.2) + Intrapartumantibiotics + MaternalGBSstatus
EOSriskatbirth = 1000 / (1 + e(-EOSrisklogit))
EOSoddsafterexam = e(EOSrisklogit) * ClinicalexamLR
EOSriskafterexam = 1000 * EOSoddsafterexam / ( 1 + EOSoddsafterexam)

 

 
Calculation Details and Variables
  • Equation parameters such as Maternal GBS status, have two or more discrete values that may be used in the calculation. The numbers in the parentheses, e.g. (0), represent the values that will be used.
