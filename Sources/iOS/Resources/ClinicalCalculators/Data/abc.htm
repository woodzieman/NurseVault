ABC Score Interpretation

 
0 to 3 points: 0.7% 30-day mortality
4 to 7 points: 9.3% 30-mortality
8 to 18 points: 34% 30-day mortality

 
 

 
Notes
  • ABC: Age, Blood tests, Comorbidities; ASA: American Society of Anesthesiologists.

 
Equations used
 
ABC Score = Age Factor + Urea Factor + Albumin Factor + Creatinine Factor + Altered Mental Status + Cirrhosis + Metastatic Cancer + ASA Factor

 

 
Calculation Details and Variables
  • Age Factor is assigned values by this ordered logic:
    • If Age ≥75 yr, Age Factor = 2
    • Else if Age ≥60 yr, Age Factor = 1
    • Else Age Factor = 0.
  • Urea Factor is assigned values by this ordered logic:
    • If Urea >10 mmol/L, Urea Factor = 1
    • Else Urea Factor = 0.
  • Albumin Factor is assigned values by this ordered logic:
    • If Albumin <30 g/L, Albumin Factor = 2
    • Else Albumin Factor = 0.
  • Creatinine Factor is assigned values by this ordered logic:
    • If Creatinine >150 mcmol/L, Creatinine Factor = 2
    • Else if Creatinine ≥100 mcmol/L, Creatinine Factor = 1
    • Else Creatinine Factor = 0.
  • Equation parameters such as Altered Mental Status, have two or more discrete values that may be used in the calculation. The numbers in the parentheses, e.g. (0), represent the values that will be used.
  • ASA Factor is assigned values by this ordered logic:
    • If ASA Score ≥4 score, ASA Factor = 3
    • Else if ASA Score ≥3 score, ASA Factor = 1
    • Else ASA Factor = 0.
