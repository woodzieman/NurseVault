Notes
  • Blood pressure (BP) percentiles for children are based on the child’s sex, age, and height.
  • Height Z-scores and height percentiles in this calculator are based on the United States Centers for Disease Control and Prevention (CDC) growth reference and are used only to determine if the height is out of range for the BP calculation. If a child's height Z-score is outside of the range -3.09 to 3.09 (which corresponds to 0.01 to 99.9 percentiles), BP percentiles cannot be calculated. For children <2 years, height Z-scores and percentiles are not shown.
  • For children <13 years, the following BP definitions are based on the 2017 American Academy of Pediatrics (AAP) guidelines:
    • Normal BP: Systolic and diastolic BP <90th percentile based on sex, age, and height
    • Elevated BP: Systolic and diastolic BP ≥90th percentile to <95th percentile or 120/80 mmHg to <95th percentile (whichever is lower)
    • Stage 1 hypertension (HTN): Systolic and diastolic BP ≥95th percentile to <95th percentile + 12 mmHg or 130/80 to 139/89 mmHg (whichever is lower)
    • Stage 2 HTN: Systolic and diastolic BP ≥95th percentile + 12 mmHg or ≥140/90 mmHg (whichever is lower)
  • For adolescents ≥13 to <18 years, BP definitions are based on adult standards as follows:
    • Normal BP: Systolic BP <120 and diastolic BP <80 mmHg
    • Elevated BP: Systolic BP 120 to 129 and diastolic BP <80 mmHg
    • Stage 1 HTN: 130/80 to 139/89 mmHg
    • Stage 2 HTN: ≥140/90 mmHg
  • The results of this calculator closely match those in the AAP/American Heart Association (AHA) guidance document.[3] Minor discrepancies compared with other resources are explained by the following approaches, which we designed to optimize sensitivity and accuracy:
    • Height-for-age Z-scores and BP percentiles are most accurately calculated when the child's age is entered as a fractional number (eg, 6.25 years). The height-for-age Z-score is only used to exclude very tall or very short children (ie, Z-scores outside the range of -3.09 to 3.09) and is not otherwise relevant to the BP percentile calculations.
    • A single BP value may correspond to several adjacent BP percentiles. In this case, this calculator selects the highest related BP percentile. This slightly improves the sensitivity for detecting elevated BP compared with other approaches.
    • Calculated threshold BP values are rounded down to the nearest integer (mmHg), and this calculator presents those rounded thresholds. Comparison of the calculated threshold BP values to those presented in the Flynn article[1] revealed 10 instances in which the authors chose to round certain BP thresholds up. They adjusted those thresholds because of discontinuities where a child of the same age but a higher height percentile had a lower BP percentile than a child with a lower height percentile (examples in table below). Rounding up removed these discontinuities.
  • The calculator is based on the tables below, which can be used as follows:
    • For all LMS tables, the row in the table corresponding to the patient-specific value is found in the first column of the table; values to be used for L (the Box-Cox power), M (the median), and S (the generalized coefficient of variation) in the equation for Z-score are retrieved.
    • Height-for-age Z-scores are calculated from CDC LMS data for infant length-for-age up to 24 months. The CDC table stature-for-age is used for age >2 years.[6]
    • Z-scores may be used to do a table lookup for the corresponding percentile in the Normal table percentiles for Z-score table (below). Numbers along the left side (Y-axis) of the table represent the first number and first decimal place of the Z-score, while the numbers along the top (X-axis) of the table represent the second decimal position of the Z-score.

Height Z-score = ((Height/M)L - 1) / (L * S)

 

 
Calculation Details and Variables
  • Calculations start by reading base variables from the tables below and calculating several other variables where x = Height and y = Age:
    • w = (y - 10) * (x - HeightFactor)
    • if ((x - t1m) < 0){ x2a = 0 } else { x2a = x - t1m }
    • if ((x - t4m) < 0){ x2b = 0 } else { x2b = x - t4m }
    • if ((x - t5m) < 0){ x2c = 0 } else { x2c = x - t5m }
    • x2 = x2a3 - (x2b3 * (t5m - t1m) / (t5m - t4m)) + (x2c3 * (t4m - t1m) / (t5m - t4m))
    • if ((x - t2m) <0){ x3a = 0 } else { x3a = x - t2m }
    • x3 = x3a3 - (x2b3 * (t5m - t2m) / (t5m - t4m)) + (x2c3 * (t4m - t2m) / (t5m - t4m))
    • if ((x -t3m) <0){ x4a = 0 } else { x4a = x - t3m }
    • x4 = x4a3 - (x2b3 * (t5m - t3m) / (t5m - t4m)) + (x2c3 * (t4m - t3m) / (t5m - t4m))
    • x2s = x2 / 100
    • x3s = x3 / 100
    • x4s = x4 / 100
    • if ((y - ta1m) <0){ y2a = 0 } else { y2a = y - ta1m }
    • if ((y - ta4m) <0){ y2b = 0 } else { y2b = y - ta4m }
    • if ((y - ta5m) <0){ y2c = 0 } else { y2c = y - ta5m }
    • y2 = y2a3 - (y2b3 * (ta5m - ta1m) / (ta5m - ta4m)) + (y2c3 * (ta4m - ta1m) / (ta5m - ta4m))
    • if ((y - ta2m) <0){ y3a = 0 } else { y3a = y - ta2m }
    • y3 = y3a3 - (y2b3 * (ta5m - ta2m) / (ta5m - ta4m)) + (y2c3 * (ta4m - ta2m) / (ta5m - ta4m))
    • if ((y - ta3m) <0){ y4a = 0 } else { y4a = y - ta3m }
    • y4 = y4a3 - (y2b3 * (ta5m - ta3m) / (ta5m - ta4m)) + (y2c3 * (ta4m - ta3m) / (ta5m - ta4m))
    • y2s = y2 / 100
    • y3s = y3 / 100
    • y4s = y4 / 100
    • if ((w - tb1m) <0){ w2a = 0 } else { w2a = w - tb1m }
    • if ((w - tb4m) <0){ w2b = 0 } else { w2b = w - tb4m }
    • if ((w - tb5m) <0){ w2c = 0 } else { w2c = w - tb5m }
    • w2 = w2a3 - (w2b3 * (tb5m - tb1m) / (tb5m - tb4m)) + (w2c3 * (tb4m - tb1m) / (tb5m - tb4m))
    • if ((w - tb2m) <0){ w3a = 0 } else { w3a = w - tb2m }
    • w3 = w3a3 - (w2b3 * (tb5m - tb2m) / (tb5m - tb4m)) + (w2c3 * (tb4m - tb2m) / (tb5m - tb4m))
    • if ((w - tb3m) <0){ w4a = 0 } else { w4a = w - tb3m }
    • w4 = w4a3 - (w2b3 * (tb5m - tb3m) / (tb5m - tb4m)) + (w2c3 * (tb4m - tb3m) / (tb5m - tb4m))
    • w2s = w2 / 10000
    • w3s = w3 / 10000
    • w4s = w4 / 10000
  • Systolic and diastolic pressures for each percentile from 1st to 99th are tabulated using the following formula where i is percentile:
    • Pressure = b0[i] + (b1[i] * x) + (b2[i] * x2s) + (b3[i] * x3s) + (b4[i] * x4s) + (ba1[i] * y) + (ba2[i] * y2s) + (ba3[i] * y3s) + (ba4[i] * y4s) + (bb1[i] * w) + (bb2[i] * w2s) + (bb3[i] * w3s) + (bb4[i] * w4s)
    • The patient's percentiles are assigned to the closest Pressure calculated above.
