Notes
  • The GRACE 2.0 Score calculator is a revised, non-linear model incorporating the 8 risk factors from the 2003 paper by Granger, et al.[3]
  • GRACE: Global Registry of Acute Coronary Events.

 
Equations used
 
GRACEScore = Math.round(AgeFactor + Heart rateFactor + SystolcBPFactor + Serum creatinineFactor + Killip + Cardiac arrest at presentation + Elevated cardiac enzymes + ST-segment deviation)

 

 
Calculation Details and Variables
  • AgeFactor is assigned values by this ordered logic:
    • If Age yr <35, AgeFactor = 0
    • Else if Age yr <45, AgeFactor = (Age - 35) * 1.8
    • Else if Age yr <55, AgeFactor = 18 + ((Age - 45) * 1.8)
    • Else if Age yr <65, AgeFactor = 36 + ((Age - 55) * 1.8)
    • Else if Age yr <75, AgeFactor = 54 + ((Age - 65) * 1.9)
    • Else if Age yr <85, AgeFactor = 73 + ((Age - 75) * 1.8)
    • Else if Age yr <90, AgeFactor = 91 + ((Age - 85) * 1.8)
    • Else AgeFactor = 100.
  • HeartRateFactor is assigned values by this ordered logic:
    • If Heart rate beats/min <70, HeartRateFactor = 0
    • Else if Heart rate beats/min <80, HeartRateFactor = (Heart_Rate - 70) * 0.3
    • Else if Heart rate beats/min <90, HeartRateFactor = 3 + ((Heart_Rate - 80) * 0.2)
    • Else if Heart rate beats/min <100, HeartRateFactor = 5 + ((Heart_Rate - 90) * 0.3)
    • Else if Heart rate beats/min <110, HeartRateFactor = 8 + ((Heart_Rate - 100) * 0.2)
    • Else if Heart rate beats/min <150, HeartRateFactor = 10 + ((Heart_Rate - 110) * 0.3)
    • Else if Heart rate beats/min <200, HeartRateFactor = 22 + ((Heart_Rate - 150) * 0.3)
    • Else HeartRateFactor = 34.
  • SystolcBPFactor is assigned values by this ordered logic:
    • If Systolic BP mmHg <80, SystolcBPFactor = 40
    • Else if Systolic BP mmHg <100, SystolcBPFactor = 40 - ((Systolic_BP - 80) * 0.3)
    • Else if Systolic BP mmHg <110, SystolcBPFactor = 34 - ((Systolic_BP - 100) * 0.3)
    • Else if Systolic BP mmHg <120, SystolcBPFactor = 31 - ((Systolic_BP - 110) * 0.4)
    • Else if Systolic BP mmHg <130, SystolcBPFactor = 27 - ((Systolic_BP - 120) * 0.3)
    • Else if Systolic BP mmHg <140, SystolcBPFactor = 24 - ((Systolic_BP - 130) * 0.3)
    • Else if Systolic BP mmHg <150, SystolcBPFactor = 20 - ((Systolic_BP - 140) * 0.4)
    • Else if Systolic BP mmHg <160, SystolcBPFactor = 17 - ((Systolic_BP - 150) * 0.3)
    • Else if Systolic BP mmHg <180, SystolcBPFactor = 14 - ((Systolic_BP - 160) * 0.3)
    • Else if Systolic BP mmHg <200, SystolcBPFactor = 8 - ((Systolic_BP - 180) * 0.4)
    • Else SystolcBPFactor = 0.
  • SerumCreatinineFactor is assigned values by this ordered logic:
    • If Serum creatinine mg/dL <0.2, SerumCreatinineFactor = Serum_Creatinine * 5
    • Else if Serum creatinine mg/dL <0.4, SerumCreatinineFactor = 1 + ((Serum_Creatinine - 0.2) * 10)
    • Else if Serum creatinine mg/dL <0.6, SerumCreatinineFactor = 3 + ((Serum_Creatinine - 0.4) * 5)
    • Else if Serum creatinine mg/dL <0.8, SerumCreatinineFactor = 4 + ((Serum_Creatinine - 0.6) * 10)
    • Else if Serum creatinine mg/dL <1.0, SerumCreatinineFactor = 6 + ((Serum_Creatinine - 0.8) * 5)
    • Else if Serum creatinine mg/dL <1.2, SerumCreatinineFactor = 7 + ((Serum_Creatinine - 1.0) * 5)
    • Else if Serum creatinine mg/dL <1.4, SerumCreatinineFactor = 8 + ((Serum_Creatinine - 1.2) * 10)
    • Else if Serum creatinine mg/dL <1.6, SerumCreatinineFactor = 10 + ((Serum_Creatinine - 1.4) * 5)
    • Else if Serum creatinine mg/dL <1.8, SerumCreatinineFactor = 11 + ((Serum_Creatinine - 1.6) * 10)
    • Else if Serum creatinine mg/dL <2.0, SerumCreatinineFactor = 13 + ((Serum_Creatinine - 1.8) * 5)
    • Else if Serum creatinine mg/dL <3.0, SerumCreatinineFactor = 14 + ((Serum_Creatinine - 2.0) * 7)
    • Else if Serum creatinine mg/dL <4.0, SerumCreatinineFactor = 21 + ((Serum_Creatinine - 3.0) * 7)
    • Else SerumCreatinineFactor = 28.
  • Equation parameters such as Killip, have two or more discrete values that may be used in the calculation. The numbers in the parentheses, e.g. (0), represent the values that will be used.
  • All equation coefficients were adapted from the Fox article supplemental material[1] Copyright 1998-2014, Center for Outcomes Research, University of Massachusetts Medical School.
